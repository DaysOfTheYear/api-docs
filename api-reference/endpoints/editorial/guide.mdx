## Overview

Returns editorial guide content for a month or a specific day (e.g. "April" or "15th of the month"). The path uses **no year** — only `MM` or `MM/DD` — so you request by month or day-of-month slot. The content reflects the **nearest iteration** for the year and is typically revised about **90 days before** the date occurs, so we can capture both fixed and variable events and maintain our curation of the world's holidays.

<Info>
This endpoint is available to all authenticated API tiers (Free, Pro, Enterprise, and Internal).
</Info>

## Endpoint

```
GET /api/v2/guide/{guide_date}
```

## Path Parameters

<ParamField path="guide_date" type="string" required={true}>
  Guide date in one of the following formats (no year):
  - `MM` — Two-digit month (01–12). Returns the month-level guide (e.g. "April").
  - `MM/DD` — Month and day (e.g. `04/15`). Returns the day-level guide for that day of the month.
  
  Invalid format or invalid date (e.g. `04/31`) returns 400 Bad Request.
  
  Examples: `04`, `04/15`
</ParamField>

## Request Examples

### Month guide (April)

```bash
curl -H 'X-Api-Key: YOUR_API_KEY' \
  'https://www.daysoftheyear.com/api/v2/guide/04'
```

### Day guide (15th of the month)

```bash
curl -H 'X-Api-Key: YOUR_API_KEY' \
  'https://www.daysoftheyear.com/api/v2/guide/04/15'
```

## Response

### Success Response (200 OK)

```json
{
  "code": 200,
  "meta": {
    "cache_status": "MISS",
    "request_type": "GUIDE"
  },
  "message": "Please remember; your free use of this API requires full attribution...",
  "data": {
    "id": 123,
    "content": "<p>Full HTML content of the guide...</p>",
    "excerpt": "Short excerpt text.",
    "snippet": "Optional snippet from custom field.",
    "type": "month",
    "last_updated": "2026-01-15"
  }
}
```

<Note>
The `message` field is only present for Free tier; Pro, Enterprise, and Internal tiers do not receive the attribution message.
</Note>

### Response Fields

<ResponseField name="id" type="integer">
  Post ID of the guide.
</ResponseField>

<ResponseField name="content" type="string">
  Full HTML content of the guide page.
</ResponseField>

<ResponseField name="excerpt" type="string">
  Short excerpt or empty string if not set.
</ResponseField>

<ResponseField name="snippet" type="string">
  Optional snippet from a custom field, or empty string.
</ResponseField>

<ResponseField name="type" type="string">
  Type of guide: `"month"` or `"day"`.
</ResponseField>

<ResponseField name="last_updated" type="string">
  Date the guide was last revised, in `YYYY-MM-DD` format.
</ResponseField>

## Error Responses

### 400 Bad Request

Invalid guide date format (e.g. year included, or invalid day like 04/31):

```json
{
  "code": 400,
  "message": "Invalid guide date; use MM or MM/DD only.",
  "data": []
}
```

### 404 Not Found

No guide exists for the requested date:

```json
{
  "code": 404,
  "message": "Guide not found for this date.",
  "data": []
}
```

### 401 Unauthorized / 403 Forbidden

Missing or invalid API key, or endpoint not available for your tier:

```json
{
  "code": 403,
  "message": "Authentication required"
}
```

## Notes

- Guide date format (`MM` or `MM/DD`) is **not** the same as the `/date/{date}` endpoint, which uses `YYYY/MM` or `YYYY/MM/DD` and includes the year.
- Content is updated roughly 90 days before the date to capture both fixed and variable events; use `last_updated` to see when the guide was last revised.
